# Vanilla JS Calculator

A web-based calculator built with plain HTML, CSS, and JavaScript. This project demonstrates core DOM manipulation, event handling, and basic state management.

## Specification

- I have chosen to implement this calculator using the *Immediate Execution* model.
- This allows me to focus on mastering JavaScript DOM event handling and avoid the engineering complexity of implementing an expression parser.
- Operator precedence has also deliberately been omitted to simplify the logic.
